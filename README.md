# Useful PowerShell scripts collection
## Purpose and usage
I created this repository to store and share PS scripts I use to get around some of the Windows 11 inconveniences or bugs I come across. Scripts here are useful to me, but may need modifications or may not be useful at all to someone else. Please take a minute to read through the script yourself and make sure it is suitable for the task at hand, before running them on your machine.

## Scripts
### layouts_cleanup.ps
The purpose of this script is to recreate the user's language list and (optionally) choose the desired keyboard layout for each language, as a way to quickly clean up the typing layouts Windows 11 adds automatically from time to time. You will probably need to modify the languages and layouts set.
